👋 Hello from swift-pwa

A system webview (WKWebView / WebKitGTK / WebView2) driven from Swift, with the __SWIFT_PWA__ bridge wired up at document start.

Shortcuts: ⌘R rename · ⌘1 800×600 · ⌘2 1024×768 · ⌘T server time · ⇧⌘C copy title · ⇧⌘V paste · ⌘K clear log

Window

Title and size go through WindowPlugin's main-actor-hopping invokes.

Bridge

Round-trip a JSON envelope through BridgeRuntime — minimal proof the dispatcher is alive.

Clipboard

Reads and writes via the host's pasteboard: NSPasteboard on macOS, UIPasteboard on iOS, GdkClipboard on Linux, the Win32 Clipboard API on Windows.

Tray

System tray icon plus popup menu. iOS and the GTK4 backend log a one-shot warning instead — no system tray on iOS, and libayatana-appindicator3 can't be reused from a GTK4 process.

Dialogs

Native message / confirm / file pickers via DialogPlugin — each backend wires its platform's HIG dialog (NSAlert/NSOpenPanel, UIAlertController, GtkFileChooser, IFileOpenDialog).

A pick also hands back a bookmark per path — an opaque token that keeps the location reachable after the app restarts, which on iOS and Android the path alone can't do. Remember folder stores one; quit, relaunch, and Reopen remembered redeems it via dialog.resolveBookmark and lists the folder.

Filesystem

Round-trip a scratch file via FsPlugin: fs.writeText, fs.readText, fs.metadata, fs.remove. Path comes back from dialog.saveFile / picks a temp file when cancelled. Foundation-backed, same surface on every host.

Content packs

Extract a .zip natively (fs.extractZip, bytes never cross the bridge) into the app's data dir, then serve the media by an origin-relative URL via ctx.serveDirectory("/packs"). Import pack runs the real dialog.openFile → fs.listZip / fs.extractZip flow (a content:// SAF URI on Android, a path on desktop).

Biometrics

Cross-platform biometric.canAuthenticate + biometric.authenticate. Touch ID / Face ID / Optic ID on Apple, Windows Hello on Windows, stub on Linux (no clean cross-distro primitive).

Updater

Cross-platform updater.check / run / installAndRelaunch. A synthetic DemoUpdater streams a fake progress arc so the bar fills without a release server; production apps swap in the real platform backend against a signed manifest.

Notifications

Cross-platform notifications.send. The second button sends a fixed Windows toast (look for it in Action Center under SwiftPWA.HelloPWA); on macOS / Linux both send a regular notification.

Device & location

Your page's own getUserMedia works because something finally answers the webview's permission request. Location goes through geo.*, because macOS can't grant navigator.geolocation at all.

Each switch is the app's own control, above the OS prompt. It reaches geo.* everywhere; capture is gated on Linux and Android so far, and takes the platform's own answer on macOS, iOS and Windows.

Switched off, the buttons go — but it's enforced in Swift, not by hiding them. Ask anyway.

Duplex session

Two-way over one open subscription: push frames in while the Swift handler streams a running total back — a plain subscribe can only listen. Flood overruns the bounded buffer, so the oldest frames drop.
