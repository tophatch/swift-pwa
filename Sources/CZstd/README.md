# CZstd — vendored Zstandard decoder

A SwiftPM C target wrapping a **single-file amalgamation of Zstandard's
decompressor** (`zstddeclib.c`), used by the updater backends to
reconstruct a delta (binary-patch) update from the installed artifact +
a `zstd --patch-from` patch. Compiled from source into whatever links it,
so there is **no system libzstd / vcpkg / prebuilt-DLL dependency** on any
platform — the same reason `CStbImage` vendors stb.

Only the *decoder* is vendored: the runtime only ever decompresses. The
publish side (`swift-pwa updater diff` / `manifest --delta`) shells out to
the full `zstd` CLI for compression.

## Provenance

- Upstream: [facebook/zstd](https://github.com/facebook/zstd) **v1.5.7**
  (BSD-2-Clause / GPLv2 dual-licensed; the license header is preserved at
  the top of `zstddeclib.c`).
- `zstddeclib.c` generated by upstream's
  `build/single_file_libs/create_single_file_decoder.sh`
  (`combine.py -r ../../lib -x legacy/zstd_legacy.h -o zstddeclib.c zstddeclib-in.c`).
- `include/zstd.h` and `include/zstd_errors.h` are the upstream public
  headers verbatim (declarations only; the module map exposes them to Swift).

## Regenerating (version bump)

```sh
curl -sSL -o zstd.tgz https://github.com/facebook/zstd/releases/download/v<X.Y.Z>/zstd-<X.Y.Z>.tar.gz
tar xzf zstd.tgz && cd zstd-<X.Y.Z>/build/single_file_libs
bash create_single_file_decoder.sh   # -> zstddeclib.c
cp zstddeclib.c        <repo>/Sources/CZstd/zstddeclib.c
cp ../../lib/zstd.h    <repo>/Sources/CZstd/include/zstd.h
cp ../../lib/zstd_errors.h <repo>/Sources/CZstd/include/zstd_errors.h
```
